
# Jolla_2026_Phone_Case_-_TPU
Model for TPU Case for Jolla 2026. Tested to print with TPU95A on Ender 3 V3 SE

Settings (may or may not suit your printer):
* 0.4 mm nozzle,
* 220°C nozzle (230°C first layer), 40°C bed,
* 0.2 mm layer height,
* 60 mm/s perimeter (30 small, 60 external) speed ,100 mm/s infill speed (set these speeds to half of this, if you want better results and are patient!)
* 25% infill
* 2 mm retraction at 40 mm/s.
Feel free to comment if you have other suitable TPU settings... I had to cut away some garbage.

The model comes with separate case and bumper. You can glue the parts together, but they should stay in place without glue. You will need supports, otherwise the bumper and the holes will not print properly. The 1 mm version comes with a closed button for the volume key, 2 and 3 mm version have a hole instead.

I've added the Freecad (1.1.3) file as well (Jolla26_Case.FCStd). Feel free to fork / commit / whatever, though it might be a little chaotic (one of the first models, as I wrote :) )
If you want to see how it looks, go to https://www.thingiverse.com/thing:7426007.

You can use Jolla26_Case_1mm.3mf for bumper + case with 1mm thickness or the single files Jolla26_Case-Cut_bumper_Xmm.3mf and Jolla26_Case-Cut_Huelle_Xmm.3mf - for thickness X. Combining different thicknesses for bumper and case will not fit exactly.

I used the dimensions from Benpaz "Jolla Phone Case (2026)" on 3DSEARCH (https://3dsearch.net/model/jolla-phone-case-2026-1829526).
